## 一、目标

Debian 桌面应用（X11/GL/任意）的**实时帧流** → 桥接服务 → SurfaceFlinger → hwcomposer.mt6755.so → Mali-T860 GPU 合成 → 物理屏幕。
取代 `debian_to_screen.sh` 的秒级中转，做到实时。

## 二、桥接服务架构

```
Debian 应用 ──unix socket + 共享内存──> 桥接服务(bionic, chroot /system)
                                          │ SurfaceComposerClient(libgui)
                                          ▼
                                      SurfaceFlinger → hwcomposer → 屏幕
```

- 桥接服务是**唯一通道**，接口固定，**不 bind /system 进 Debian**（避免污染环境，用户明确要求）
- 桥接服务在 chroot /system 内用 bionic + 设备 libgui.so，纯原生栈

## 四、卡点（精确定位）

运行 `bridge_server` 时：
```
WARNING: linker: /tmp/bridge_server: unsupported flags DT_FLAGS_1=0x8000001
[bridge] start sock=/data/local/tmp/bridge.sock 1080x1920
EXIT=138   ← SIGBUS 崩
```

- linker 活了（start 打印出来）
- 崩在 `client.createSurface(...)` 这步（String8 构造之后）
- **根因**：源码里 `String8` 类是**手工声明**的（`void* mData` 占位），与设备 libgui/libui 的真实 `String8` ABI（RefBase 继承 + 内部结构）不一致 → 构造时写坏内存 → SIGBUS
- 同理 `sp<T>`、`Surface`、`SurfaceControl` 的手工声明都有 ABI 风险

## 五、继续的切入点（三条路）

### 方案 1（推荐）：用 libhybris 的 surface_flinger_compatibility_layer
- **C 接口**，把 libgui 的 C++ ABI 全封装好了，不用手工声明
- 头文件**在设备上**：`/usr/include/libhybris/include/hybris/surface_flinger/surface_flinger_compatibility_layer.h`（含 `sf_client_create`/`sf_surface_create`/`sf_surface_get_egl_surface` 等）
- 源码：`/tmp/libhybris-src/compat/surface_flinger/surface_flinger_compatibility_layer.cpp`
- **卡点**：编它需要 AOSP 头（`gui/SurfaceComposerClient.h`、`ui/DisplayInfo.h`、`ui/Region.h` 等）
- **注意**：这台是 Android 7（API 25），要 Android 7 对应 AOSP 头，不是 master

### 方案 2：修正 String8 ABI
- 从设备 `/system/lib64/libutils.so` 反汇编确认 String8 真实布局（或从 AOSP android-7.x 头拿定义）
- 手工声明改对后，桥接服务可用
- 风险：还有其他手工类（sp/Surface/SurfaceControl）可能也错

### 方案 3（已验证，秒级 fallback）
- `debian_to_screen.sh` 经 bootanimation 显示，链路完整，就是延迟高
- 可先交付此版本

## 六、AOSP 头获取失败的教训

- `raw.githubusercontent.com/aosp-mirror/platform_frameworks_native/*` 一律 404
- `android.googlesource.com/.../format=TEXT` 拉不到
- 不要再试这两条（浪费了时间）
- 若要 AOSP 头：用 `curl -sL "https://android.googlesource.com/platform/frameworks/native/+archive/refs/heads/android-7.x/include/gui.tar.gz"` 拉 tar 包，或找正确 branch
