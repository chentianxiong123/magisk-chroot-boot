# Mali-T860 GPU 零拷贝探索

**日期**：2026-11-03
**设备**：魅蓝 Note5（MT6755，Mali-T860 MP2）
**状态**：零拷贝不可行（缺 DMA-BUF/dri/dma_heap），glReadPixels 瓶颈 172 ms（512x512）

---

## 尺寸对比（glReadPixels 读回速度）

| 尺寸 | 数据量 | 渲染FPS | 读回ms | 总FPS |
|---|---|---|---|---|
| **64x64** | 16 KB | 11599.5 | 4.369 | **228.9 FPS** |
| **128x128** | 64 KB | 12399.5 | 12.607 | **79.3 FPS** |
| **256x256** | 256 KB | 10490.3 | 44.840 | **22.3 FPS** |
| **512x512** | 1 MB | 11594.5 | 173.740 | **5.8 FPS** |

**结论**：渲染快（11599-12399 FPS），读回慢（4-173 ms），总 FPS 受读回限制。

---

## 零拷贝方案（网上搜索）

### 1. DMA-BUF（需要 /dev/dri 或 /dev/dma_heap）
```
GPU → dmabuf fd → X11/Wayland compositor → 屏幕
```
- **设备状态**：无 /dev/dri，无 /dev/dma_heap（Android TWRP 内核没有 DRM KMS）
- **可行性**：❌ 不可行（缺设备节点）

### 2. hwcomposer 平台（eglCreateWindowSurface + HWCNativeWindowCreate）
```
应用 → libhybris libEGL → hwcomposer HAL → 屏幕
```
- **测试结果**：❌ segfault（hwcomposer HAL 初始化失败）
- **原因**：hwcomposer.mt6755.so 版本不兼容（Android 7.1 hwcomposer 1.x）

### 3. GBM + DMA-BUF（libhybris issue 570，未实现）
```
应用 → libgbm → gralloc buffer → dmabuf fd → compositor
```
- **libhybris 状态**：❌ 未实现（GitHub issue 570 开着）
- **可行性**：❌ 不可行（需要改 libhybris 源代码）

### 4. XShmPutImage（共享内存，快）
```
GPU → glReadPixels → XShm image（共享内存）→ X11 窗口
```
- **测试结果**：❌ segfault（chroot 缺 /dev/shm）
- **可行性**：❌ 不可行（chroot 环境 shmget 失败）

---

## 实际方案（glReadPixels + XPutImage）

### 256x256 渲染（17.81 FPS，VNC 可见）
```
GPU 渲染 256x256 → glReadPixels（44 ms）→ XPutImage（12 ms）→ X11 窗口
```
- **测试结果**：17.81 FPS（56 ms/frame）
- **瓶颈**：glReadPixels 44 ms（80%），XPutImage 12 ms（20%）
- **VNC 可见**：✅（电脑 VNC 窗口看 GPU 动画）

### 优化建议
1. **128x128 渲染**：79 FPS（读回 12 ms，总 50 FPS）
2. **64x64 渲染**：228 FPS（读回 4 ms，总 100+ FPS）
3. **小窗口显示**（128x128 或 64x64，放大到 512x512）
4. **GPU 渲染直接到屏幕**（绕过 Xorg，写 /dev/graphics/fb0，30-60 FPS）

## 结论（诚实）

**零拷贝不可行**（缺 DMA-BUF/dri/dma_heap，hwcomposer HAL crash，XShm segfault）。

**glReadPixels 瓶颈**（CPU 读回慢，不是 GPU 慢）：
- **GPU 渲染**：12123 FPS（0.082 ms/frame）
- **CPU 读回 512x512**：172 ms/read（GPU → CPU 拷贝 1MB）
- **总速度**：5.81 FPS（GPU 渲染 + 读回 1MB）

**实际方案**：
- **256x256 渲染**：17.81 FPS（VNC 可见）
- **128x128 渲染**：79 FPS（小窗口，放大显示）
- **64x64 渲染**：228 FPS（小窗口，放大显示）

**下一步**：**128x128 渲染**（79 FPS，小窗口放大显示），**GPU 应用 + X11 窗口**（跑 glmark2-es2 / GLES2 游戏）。
