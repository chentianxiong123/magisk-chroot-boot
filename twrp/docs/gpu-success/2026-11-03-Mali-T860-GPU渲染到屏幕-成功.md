## 原理（绕过 Xorg，直接写 framebuffer）

```
应用 → libhybris libEGL → Mali GPU（PBuffer 离屏渲染）
     → glReadPixels（CPU 读回）
     → mmap /dev/graphics/fb0（写 framebuffer）
     → 屏幕（看到）
```

**代码**（test-fbdev-screen.c）：
```c
// 1. Open framebuffer
int fb = open("/dev/graphics/fb0", O_RDWR);
struct fb_var_screeninfo vinfo;
ioctl(fb, FBIOGET_VSCREENINFO, &vinfo);
void* fb_mem = mmap(0, fb_size, PROT_READ | PROT_WRITE, MAP_SHARED, fb, 0);

// 2. EGL + Mali GPU（PBuffer 离屏渲染）
EGLDisplay dpy = eglGetDisplay(EGL_DEFAULT_DISPLAY);
eglInitialize(dpy, NULL, NULL);
EGLSurface surf = eglCreatePbufferSurface(dpy, cfg, pattribs);  // 512x512 PBuffer
eglMakeCurrent(dpy, surf, surf, ctx);

// 3. Render loop（GPU 渲染 → glReadPixels → mmap 写 fb0）
for (int frame = 0; frame < 60; frame++) {
    glClear(GL_COLOR_BUFFER_BIT);
    glDrawArrays(GL_TRIANGLE_FAN, 0, 4);  // Full-screen quad + shader
    glFinish();
    glReadPixels(0, 0, 512, 512, GL_RGBA, GL_UNSIGNED_BYTE, pixels);  // GPU → CPU
    // Convert RGBA → BGRA + write to fb0
    for (int y = 0; y < 512; y++) {
        for (int x = 0; x < 512; x++) {
            fb_ptr[dst_idx + 0] = b;
            fb_ptr[dst_idx + 1] = g;
            fb_ptr[dst_idx + 2] = r;
            fb_ptr[dst_idx + 3] = 255;
        }
    }
    usleep(16667);  // 60 FPS
}
```

## 与 Xorg 冲突（不能同时跑）

**问题**：GPU 应用写 fb0 + Xorg 写 fb0 → 冲突（画面闪烁）

**解决方法**：
1. **停 Xorg**（`pkill -9 Xorg`），GPU 应用独占 fb0
2. **GPU 应用用 X11 窗口**（不直接写 fb0，通过 Xorg 显示）
3. **GPU 应用用 X11 窗口 + GPU 渲染**（最实际，Xorg + GPU 应用共存）
