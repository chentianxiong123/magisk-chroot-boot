## 卡住（桌面级 GPU 合成）

### 问题 1：weston drm-backend 失败
```
no drm device found
fatal: failed to create compositor backend
```
**原因**：Android TWRP 内核没有 /dev/dri 设备（Android 用 hwcomposer，不是 DRM KMS）

### 问题 2：weston x11-backend 段错误
```
warning: either no EGL_EXT_platform_base support or specific platform support
library "libpq_cust_base.so" not found
library "libwlparser.so" not found
Segmentation fault
```
**原因**：libhybris eglplatform_wayland 需要 Wayland compositor（不是 X11）

### 问题 3：hwcomposer 平台 eglCreateWindowSurface crash
```
EGL_VENDOR: Android
EGL_VERSION: 1.4 Android META-EGL
Config: 1 matches
Context: OK (GLES2)
Segfault（eglCreateWindowSurface(0) crash）
```
**原因**：hwcomposer 平台需要 ANativeWindow（不是 0）

## 真实方案（3 个）

### 方案 1：**应用级 GPU 加速 + X11 窗口**（已经跑通，最实际）
```
应用 → libhybris libEGL → Mali GPU（PBuffer 离屏渲染）
     → glReadPixels → XPutImage → X11 窗口（软件拷贝）
```
- **GPU 渲染**：Mali-T860 硬件加速（17654 FPS 离屏）
- **软件拷贝**：glReadPixels + XPutImage（30-60 FPS 显示）
- **时间**：0 小时（已经跑通）

### 方案 2：**drm-hwcomposer-shim + Flick compositor**（Mer/Droidian 方案，最成熟）
```
Wayland compositor → drm-hwcomposer-shim → Android hwcomposer → libhybris → Mali GPU
```
- **drm-hwcomposer-shim**：Rust 项目（Droidian 用，2025 daily driver）
- **时间**：4-8 小时（编译 Rust + 配置）
- **风险**：魅蓝 Note5 可能不兼容（drm-hwcomposer-shim 只测了 Pixel 3a）

### 方案 3：**weston + drm-backend + drm-hwcomposer-shim**（最完整）
```
weston → drm-backend → drm-hwcomposer-shim → Android hwcomposer → libhybris → Mali GPU
```
- **weston**：Wayland compositor（Debian 有，14.0.2）
- **drm-hwcomposer-shim**：桥接 DRM → hwcomposer
- **时间**：4-8 小时（编译 + 配置）
- **风险**：同方案 2
