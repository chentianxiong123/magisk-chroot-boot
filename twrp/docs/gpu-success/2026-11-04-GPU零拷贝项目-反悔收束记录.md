# 2026-11-04 结尾：GPU 零拷贝 / SurfaceFlinger 项目 —— 反悔与收束

> 结论一句话：这个项目**跟错了、没做成、后悔了**。记录到此为止，不再追。

## 一、为什么后悔

从头到尾，这个「魅蓝 Note5 TWRP/chroot 里跑 Mali-T860 GPU 零拷贝 + SurfaceFlinger 桌面合成」的探索，
投入了大量精力、反复折腾、一度好像要成了，最后：

- **GPU 零拷贝（SF→hwcomposer→屏幕）确实跑通了**，能显示图、能显示动画、用户亲眼确认过；
- 但 **真正想要的东西——Debian 桌面实时画面经 GPU 上屏** —— 始终没有稳定落地：
  - libhybris 直连 hwcomposer：撞墙（no session / kmap=0 / 函数表 NULL）
  - 桥接服务（libgui SurfaceComposerClient）：手工 ABI 崩（SIGBUS），缺 AOSP 头
  - 屏幕 180° 倒转、property 读不到、chroot 环境各种脆
- 我花了大量时间在 libgui、AOSP 头、linker 上反复打转，**产出和投入完全不成比例**。

**核心认知**：手机上跑 GPU 桌面这条路，对我的服务器目的来说根本不该走。
手机真正的价值是**无头低功耗服务器**（supervisord 管 web 服务），GPU 显示是伪需求。
为一个用不上的画面折腾这么多，**纯属浪费时间，后悔跟了这个方向**。

## 二、今天做了什么（清场）

用户最终决定收掉这个方向，手机恢复无头服务器状态：

- 杀 GPU 进程（surfaceflinger / servicemanager / bootanimation）
- 删 /data/chroot-system（GPU chroot）
- 还原 /system（删我建的 hwcomposer/gralloc default symlink、bootanimation 还原原厂）
- Debian 卸载桌面：Xorg / jwm / lxpanel / openbox / weston / Xwayland / x11vnc / glmark2
- 删 libhybris 二进制 + 头文件
- 删 Rust 工具链（/.rustup + /.cargo，~545M）
- apt autoremove 清 115 个孤儿包（ffmpeg / gstreamer / 语音 / 远程桌面等）
- 清 npm / cache 缓存
- 删 3D 压测游戏：supertuxkart(699M)/neverball(112M)/extremetuxracer/teeworlds（GPU 压测装的）+ 连带孤儿包
- 空间：6.3G → 4.2G（释放 ~2.1G）

**业务服务全程健康**：supervisord + 8 个 RUNNING（9router / cpa / freellmapi / openlist / batt / picoclaw-gateway / picoclaw-web / sshd）

## 四、教训

1. **不要为用不上的功能消耗服务器设备**——手机是服务器，不是 GPU 试炼场。
2. **技术上有成就（零拷贝跑通）≠ 方向正确**——目标错了，跑得再顺也是白跑。
3. **早该止损**：libhybris/桥接卡壳时就应该意识到这个方向对服务器无益，而不是反复硬啃。

—— 记录到此，收束。
