## 推荐：drm-hwcomposer-shim + Flick compositor（方案 A）

### 原理
```
Wayland 应用 → Flick compositor → drm-hwcomposer-shim → Android hwcomposer → libhybris → Mali GPU
                                      ↓
                              DRM/KMS 接口（兼容标准 compositor）
```

### 关键项目
- **Flick compositor**：https://github.com/ruapotato/Flick（Rust，mobile-first）
- **drm-hwcomposer-shim**：https://github.com/ruapotato/Flick/blob/main/drm-hwcomposer-shim
- **实测**：Pixel 3a，1080x2220 @ 60Hz，硬件加速所有应用
- **依赖**：Rust 1.70+，libhybris-common，libhybris-dev，hwc2_compat_layer

### 编译步骤（Droidian 设备上）
```bash
# 1. 安装依赖
sudo apt install libhybris-common libhybris-dev
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 2. Clone Flick
git clone https://github.com/ruapotato/Flick.git
cd Flick/drm-hwcomposer-shim

# 3. 编译 drm-hwcomposer-shim
cargo build --release

# 4. 测试
./target/release/test_hwc

# 5. 编译 Flick compositor
cd ..
cargo build --release

# 6. 运行
./target/release/flick
```

### 时间预估
- **安装依赖**：30 分钟
- **编译 drm-hwcomposer-shim**：30 分钟
- **编译 Flick**：1-2 小时
- **配置 + 测试**：1-2 小时
- **总计**：4-8 小时

### 风险
- **X11/XWayland 应用不支持**（Firefox 不能用）
- **魅蓝 Note5 可能不兼容**（drm-hwcomposer-shim 只测了 Pixel 3a）
- **Rust 编译慢**（设备上编译，可能需要 1-2 小时）

## 关键问题（需要验证）

### 1. drm-hwcomposer-shim 支持 mali_kbase r12p1 吗？
- **只测了 Pixel 3a**（Adreno 615）
- **魅蓝 Note5**（Mali-T860 MP2）**可能不兼容**
- **验证方法**：编译 drm-hwcomposer-shim，测试 hwcomposer.mt6755.so

### 2. Flick compositor 支持 arm64 吗？
- **Flick 是 Rust 项目**，应该支持 arm64
- **验证方法**：编译 Flick，看能不能跑

### 3. libhybris hwcomposer 平台能用吗？
- **test-gles2**：hwcomposer 平台 eglCreateContext OK
- **test-screen**：hwcomposer 平台 eglCreateWindowSurface crash
- **验证方法**：用 drm-hwcomposer-shim，看能不能绕过 eglCreateWindowSurface
