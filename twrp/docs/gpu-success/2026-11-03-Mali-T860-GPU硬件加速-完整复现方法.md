## 完整编译步骤（电脑交叉编译 arm64）

### 1. 准备编译环境
```bash
sudo apt install -y autoconf automake libtool pkg-config m4 \
    gcc-aarch64-linux-gnu g++-aarch64-linux-gnu patchelf
```

### 2. Clone 源代码
```bash
cd /dev/shm && mkdir libhybris-build && cd libhybris-build

# libhybris（含 TLS patcher，commit f47e718）
git clone https://github.com/libhybris/libhybris.git
cd libhybris
git checkout f47e718

# Android headers（halium-7.1 分支）
cd ..
git clone -b halium-7.1 https://github.com/Halium/android-headers.git
```

### 3. 补丁 gralloc.c（halium-7.1 headers 缺声明）
```bash
cd libhybris/hybris/gralloc

# 在 #include <hardware/gralloc.h> 后加
# extern native_handle_t* native_handle_clone(const native_handle_t* handle);
```

### 4. autogen + configure
```bash
cd /dev/shm/libhybris-build/libhybris/hybris

NOCONFIGURE=1 ./autogen.sh

./configure --host=aarch64-linux-gnu \
    --with-android-headers=/dev/shm/libhybris-build/android-headers \
    --enable-arch=arm64 --enable-trace --disable-glvnd --prefix=/usr
```

### 5. 编译（make）
```bash
cd /dev/shm/libhybris-build/libhybris

make -j12 -C common      # libhybris-common.so（含 TLS patcher）
make -j12 -C egl         # libEGL.so
make -j12 -C glesv2      # libGLESv2.so
make -j12 -C glesv1      # libGLESv1_CM.so
make -j12 -C gralloc     # libgralloc.so
make -j12 -C libsync     # libsync.so
make -j12 -C hardware    # libhardware.so.2（glibc 版，包装 Android libhardware.so）
make -j12 -C platforms   # libhybris-platformcommon.so
make -j12 -C egl/platforms  # eglplatform_null.so + eglplatform_fbdev.so + eglplatform_hwcomposer.so
```

### 6. patchelf 修复 gralloc.so（关键修复 1）
```bash
cd /dev/shm/libhybris-build/libhybris

# 移除 bionic libhardware.so.2 依赖
patchelf --remove-needed libhardware.so.2 gralloc/.libs/libgralloc.so.1.0.0

# 加回 libhybris 的 glibc 版 libhardware.so.2
patchelf --add-needed libhardware.so.2 gralloc/.libs/libgralloc.so.1.0.0
```

## 完整部署步骤（设备）

### 1. 推送编译产物（电脑 → 设备）
```bash
S=192.168.31.213:5555
B=/dev/shm/libhybris-build/libhybris

# 推到设备 /usr/lib/libhybris/
adb -s $S shell "mkdir -p /data/debian/usr/lib/libhybris/linker"

# common（含 TLS patcher）
adb -s $S push $B/common/.libs/libhybris-common.so.1.0.0 /data/debian/usr/lib/libhybris/

# EGL/GLES
adb -s $S push $B/egl/.libs/libEGL.so.1.0.0 /data/debian/usr/lib/libhybris/
adb -s $S push $B/glesv2/.libs/libGLESv2.so.2.0.0 /data/debian/usr/lib/libhybris/
adb -s $S push $B/glesv1/.libs/libGLESv1_CM.so.1.0.1 /data/debian/usr/lib/libhybris/

# gralloc（patchelf 修复后）
adb -s $S push $B/gralloc/.libs/libgralloc.so.1.0.0 /data/debian/usr/lib/libhybris/
adb -s $S push $B/libsync/.libs/libsync.so.2.0.0 /data/debian/usr/lib/libhybris/

# hardware（glibc 版，包装 Android libhardware.so）
adb -s $S push $B/hardware/.libs/libhardware.so.2.0.0 /data/debian/usr/lib/libhybris/libhardware.so.2

# platformcommon
adb -s $S push $B/platforms/common/.libs/libhybris-platformcommon.so.1.0.0 /data/debian/usr/lib/libhybris/
adb -s $S push $B/egl/platforms/common/.libs/libhybris-eglplatformcommon.so.1.0.0 /data/debian/usr/lib/libhybris/

# eglplatform（null/fbdev/hwcomposer）
adb -s $S push $B/egl/platforms/null/.libs/eglplatform_null.so /data/debian/usr/lib/libhybris/
adb -s $S push $B/egl/platforms/fbdev/.libs/eglplatform_fbdev.so /data/debian/usr/lib/libhybris/
adb -s $S push $B/egl/platforms/hwcomposer/.libs/eglplatform_hwcomposer.so /data/debian/usr/lib/libhybris/

# Android bionic linker
adb -s $S push $B/common/.libs/n.so /data/debian/usr/lib/libhybris/linker/n.so
```

## 三个关键修复（必须记住）

### 修复 1：patchelf 移除 gralloc.so 的 bionic libhardware.so.2
```bash
# 编译后（设备部署前）
patchelf --remove-needed libhardware.so.2 gralloc/.libs/libgralloc.so.1.0.0
patchelf --add-needed libhardware.so.2 gralloc/.libs/libgralloc.so.1.0.0
```
**原因**：gralloc.so NEEDED bionic libhardware.so.2 → glibc ld.so 加载 bionic libc.so → TLS 冲突 → 崩

### 修复 2：HYBRIS_TLS_PATCH=1（patch Mali blob 的 TLS 偏移量）
```bash
# 每次测试前设置环境变量
export HYBRIS_TLS_PATCH=1
```
**原因**：Mali blob（libGLES_mali.so）内联访问 bionic TLS 槽 → 和 glibc TLS 槽撞车 → segfault

### 修复 3：libhybris 的 glibc libhardware.so.2（包装 Android libhardware.so）
```bash
# 编译（不要用 Android bionic libhardware.so）
make -j12 -C hardware  # libhardware.so.2（glibc 版，HYBRIS_IMPLEMENT_FUNCTION 包装）
```
**原因**：gralloc.so 直接链接 Android bionic libhardware.so.2 → 拉入 bionic libc.so → TLS 冲突
