## 关键修复（3 个，已归档到 GitHub commit d4011bd）

1. **patchelf 移除 gralloc.so 的 bionic libhardware.so.2**（改成 libhybris 的 glibc 包装版）
2. **HYBRIS_TLS_PATCH=1**（patch Mali blob 的 TLS 偏移量，避免和 glibc 撞车）
3. **libhybris 的 glibc libhardware.so.2**（包装 Android libhardware.so，不直接加载 bionic）

## 桌面集成（下一步，2-4 小时）

### 方案 A：Wayland compositor + libhybris EGL（Mer/Sailfish 方案，推荐）
- **weston** 或 **sway**（Wayland compositor）
- **libhybris EGL/GLES**（Mali GPU 加速）
- **XWayland**（跑 X11 应用）
- **时间**：2-4 小时
- **参考**：
  - Mer 博客：http://mer-project.blogspot.com/2013/05/wayland-utilizing-android-gpu-drivers.html
  - qt5-qpa-hwcomposer-plugin：https://github.com/mer-hybris/qt5-qpa-hwcomposer-plugin

### 方案 B：Xorg + libhybris EGL（简单，但可能没有 arm64 版）
- **Xorg + glamor**（用 libhybris libEGL 做 2D 加速）
- **时间**：1-2 小时
- **风险**：可能没有 arm64 版 xorg-driver-libhybris

### 方案 C：应用级 GPU 加速（不集成桌面，最实际）
- **应用直接用 libhybris libEGL**（渲染 PBuffer，输出到文件/网络）
- **时间**：30 分钟（已经跑通，只需要应用支持 EGL）
- **例子**：glmark2-es2 + libhybris libEGL
