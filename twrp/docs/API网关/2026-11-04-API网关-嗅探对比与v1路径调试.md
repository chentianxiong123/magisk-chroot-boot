# API 网关请求嗅探对比：`/v1` 路径问题排查

> 2026-11-04 · 本地搭"假供应商服务器"嗅探 ccswitch 与 cpa 发往上游的 `/models` 请求差异。
> 结论：**不通先看路径，base-url 加/减 `/v1` 试试**；UA 是网关硬编码，改不了。

---

## 1. 起因

同一个上游，**ccswitch 调用正常，cpa 调用不行**。怀疑两者发往上游的请求有差异，需要抓出来。重点看 `/models`（模型列表）接口。

## 2. 方法：本地起一个"假供应商"嗅探服务器

思路：不接真上游，本地起一个**假的 OpenAI/Anthropic 供应商**，让 ccswitch 和 cpa 都把上游指到它。它把**每个请求的 method / path / headers / body 完整记下来**，再回个假响应。这样谁发了什么、怎么发的，一目了然。

脚本 `fake_supplier.py`（监听 `0.0.0.0:8777`，记录到 `fake_upstream.log`）：

```python
#!/usr/bin/env python3
import http.server, json, time, sys
PORT = int(sys.argv[1]) if len(sys.argv) > 1 else 8777
LOGF = sys.argv[2] if len(sys.argv) > 2 else '/tmp/opencode/fake_upstream.log'
def log(s):
    line = f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] {s}"
    print(line, flush=True)
    with open(LOGF, 'a') as f: f.write(line + '\n')
class H(http.server.BaseHTTPRequestHandler):
    protocol_version = 'HTTP/1.1'
    def _do(self):
        n = int(self.headers.get('Content-Length') or 0)
        body = self.rfile.read(n) if n else b''
        log('=' * 70); log(f'{self.command} {self.path}')
        log('HEADERS: ' + json.dumps(dict(self.headers), ensure_ascii=False))
        if body: log('BODY: ' + body.decode('utf-8', 'replace'))
        p = self.path.split('?')[0]
        if p in ('/v1/models', '/models'):
            self._json({'object': 'list', 'data': [
                {'id': 'fake-1', 'object': 'model', 'created': 0, 'owned_by': 'fake'},
                {'id': 'fake-auto', 'object': 'model', 'created': 0, 'owned_by': 'fake'}]})
        elif p in ('/v1/chat/completions', '/v1/completions'):
            self._json({'id': 'chatcmpl-fake', 'object': 'chat.completion', 'created': 0,
                        'model': 'fake-1', 'choices': [{'index': 0,
                        'message': {'role': 'assistant', 'content': 'pong'},
                        'finish_reason': 'stop'}],
                        'usage': {'prompt_tokens': 1, 'completion_tokens': 1, 'total_tokens': 2}})
        elif p == '/v1/messages':
            self._json({'id': 'msg_fake', 'type': 'message', 'role': 'assistant', 'model': 'fake-1',
                        'content': [{'type': 'text', 'text': 'pong'}], 'stop_reason': 'end_turn',
                        'usage': {'input_tokens': 1, 'output_tokens': 1}})
        else: self._json({'ok': True})
    def _json(self, obj):
        b = json.dumps(obj).encode()
        self.send_response(200); self.send_header('Content-Type', 'application/json')
        self.send_header('Content-Length', str(len(b))); self.end_headers(); self.wfile.write(b)
    do_GET = _do; do_POST = _do; do_PUT = _do; do_DELETE = _do; do_PATCH = _do
    def log_message(self, *a): pass
http.server.ThreadingHTTPServer(('0.0.0.0', PORT), H).serve_forever()
```

## 3. 让两边把上游指到假服务器

- **ccswitch / Claude Code**：在 cc-switch 里新建 provider，Base URL = `http://127.0.0.1:8777`，API Key 随便填（`sk-fake`），切换过去，触发 `/models`。
- **cpa（远端 8317）**：把 `/opt/CPA/config.yaml` 里某 provider 的 `base-url` 改成 `http://192.168.31.204:8777/v1`，重启 cpa（`supervisorctl restart cpa`），触发模型刷新/测试。

触发后看假服务器日志，两边各一条请求。

|---|---|---|---|
| 路径 | `GET /v1/models` | `GET /models` | `GET /v1/models` ✅ |
| UA | （无/客户端自带） | `Go-http-client/1.1` | `Go-http-client/1.1` |
| auth | `Bearer sk-fake` | `Bearer sk-fake` | `Bearer sk-fake` |

## 5. 结论

### 5.1 路径 = 元凶（可修）

- **ccswitch 打 `/v1/models`**；**cpa 打的是 `base-url + "/models"`**。
- 所以 cpa 的 base-url **带不带 `/v1` 直接决定路径**：
  - base-url = `http://host:port` → 请求 `/models`
  - base-url = `http://host:port/v1` → 请求 `/v1/models`
- 上游如果只实现 `/v1/models`，cpa 打 `/models` 就会 404/失败 → **这就是"ccswitch 行、cpa 不行"的原因**。
- **修复：cpa 的 base-url 必须带 `/v1`**（和 OpenAI 客户端一致）。

### 5.2 UA = 硬编码（改不了）

- cpa 探测 `/models` 时 UA 是 `Go-http-client/1.1`，**Go 客户端硬编码**。
- config 里 provider 的 `headers.User-Agent`（如 `opencode/1.18.30...`）**只作用于转发请求（chat/completions），不作用于探测 `/models`**。
- 所以想靠配置改探测 UA 做不到；若上游按 UA 拦截，需上游放行 `Go-http-client/1.1` 或不校验 UA。

## 6. 经验：不通就"加减 /v1"

以后任何网关"不通"，**先看它发到上游的路径**：

1. 按上面方法搭假服务器，看它实际打 `/models` 还是 `/v1/models`。
2. 对照上游真实实现支持哪个路径。
3. **在 base-url 上加 `/v1` 或减 `/v1` 调一次**，通常就通了。

不同网关拼接规则不一样：有的自动补 `/v1`，有的直接拼。**"加减 /v1"是最高频的排查手段**。
